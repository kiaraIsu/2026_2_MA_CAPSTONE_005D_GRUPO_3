## 📋 Descripción del Proyecto

**TicketIA** es una plataforma web de gestión de soporte TI pensada para el Departamento de Informática de una municipalidad en Chile. Hoy los funcionarios de las distintas direcciones municipales (Administración y Finanzas, DIDECO, Obras, Tránsito, entre otras) piden ayuda técnica por WhatsApp, llamadas o correo, sin un registro centralizado. Esto dificulta el seguimiento, la priorización y la medición del servicio.

El objetivo del proyecto es **centralizar en un solo sistema la creación, el seguimiento y la resolución de las solicitudes técnicas**. La plataforma tiene tres tipos de usuario: funcionario solicitante, técnico de soporte y administrador. Permite crear tickets con archivos adjuntos, asignarlos y priorizarlos, hacer seguimiento de su estado, agregar comentarios y consultar el historial.

Como aporte diferenciador, incorpora un **módulo de inteligencia artificial** que clasifica automáticamente la categoría y la prioridad de cada ticket a partir de la descripción escrita por el funcionario. La precisión objetivo es de al menos un 80%.

**Tecnologías principales:** Python (Flask), PostgreSQL, API REST, Docker y Git/GitHub.

**Beneficios esperados:**
- Registro centralizado y trazable de todas las solicitudes de soporte.
- Flujo de trabajo ordenado para los técnicos.
- Visibilidad y métricas para que la jefatura de informática pueda mejorar el servicio.
- Menos tiempo de clasificación manual gracias al módulo de IA.

El proyecto se desarrolla con la metodología **Scrumban** (Scrum + Kanban), en sprints de 2 semanas.
